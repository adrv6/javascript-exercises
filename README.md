# JavaScript Exercises

A collection of small JavaScript exercises I'm solving to practice and learn the language step by step. It's a companion to my [python-exercises](https://github.com/YOUR-USERNAME/python-exercises) repo.

New exercises are added gradually as I learn, so this repo is a work in progress.

## How to run an exercise

You need [Node.js](https://nodejs.org/) installed. Then, from the root of the repo:

```bash
node 01-basics/temperature.js
```

## Structure

```
javascript-exercises/
├── README.md
└── 01-basics/
    ├── temperature.js
    └── bmi.js
```

Each file starts with a comment describing the exercise, so it can be understood on its own.

## Exercises

### 01 – Basics

| Exercise | Description | Concepts |
| --- | --- | --- |
| [temperature.js](01-basics/temperature.js) | Convert a temperature from Fahrenheit to Celsius | Variables, arithmetic, `console.log` |
| [bmi.js](01-basics/bmi.js) | Calculate the Body Mass Index (BMI) from weight and height | Variables, exponent operator, `console.log` |
